# 🐹 햄스터봇 레이싱 랭킹 시스템

축제 부스(인공지능 vs 사람 햄스터봇 레이싱)에서 쓰는 실시간 랭킹 보드입니다.
GitHub Pages로 열면 누구나 랭킹을 볼 수 있고, 기록 입력은 **부스 운영 기기 한 대에서만** 가능하도록 설계했습니다.

## 구성

| 경로 | 설명 |
|---|---|
| `index.html` | 공개 랭킹 화면. GitHub Pages로 배포해 누구나 열람 |
| `admin.html` | 기록 입력 화면. **URL을 공유하지 마세요.** 부스 기기에서만 사용 |
| `src/*.ts` | TypeScript 소스 (common / ranking / admin) |
| `assets/*.js` | `npm run build`(tsc)로 컴파일된 결과물. Pages는 빌드 단계가 없으므로 반드시 커밋되어 있어야 함 |
| `data/records.json` | 랭킹 원본 데이터 (배열) |
| `data/records.txt` | 사람이 읽기 좋은 기록 로그 |

## 입력 형식

`admin.html`의 입력창에 아래 형식으로 한 줄씩 입력합니다 (여러 줄 = 여러 건 동시 등록).

```
학교,학년,나이,이름,기록(초),태그
```

- `태그`가 `1`이면 인공지능 기록으로 표시됩니다(🤖 AI 배지).
- `태그`가 `0`이거나 비어 있으면 사람 기록입니다.
- 학교/학년/나이는 인공지능 기록의 경우 비워도 됩니다.
- 랭킹은 **기록(시간) 오름차순**(기록이 낮을수록 상위)으로 정렬되며, 동시간이면 먼저 등록된 기록이 앞섭니다.

예:
```
한밭초등학교,6,12,홍길동,15.32,0
AI-러너,,,,12.05,1
```

## 랭킹 화면 규칙

- 1~3위: 화려한 시상대 박스(메달 아이콘), 등장 애니메이션
- 4~10위: 색상이 구분된 카드 안 리스트
- 11위 이하: 별도 박스, 스크롤해야 보임 (첫 화면에는 10위까지만 노출)
- 인공지능 기록은 이름 옆에 🤖 AI 배지 표시
- 모바일에서는 시상대가 세로로 쌓이고 리스트도 반응형으로 재배치됨

## 실시간 동기화 원리

1. **같은 기기(부스 화면)**: `admin.html`에서 추가한 즉시 `localStorage` + `BroadcastChannel`로 같은 브라우저의 다른 탭(랭킹 화면)에 즉시 반영됩니다.
2. **다른 기기(원격 방문자)**: `admin.html`이 GitHub REST API로 `data/records.json`, `data/records.txt`를 저장소에 직접 커밋합니다. GitHub Pages가 재배포되면(보통 수십 초 내) `index.html`이 8초 간격 폴링으로 최신 데이터를 가져옵니다.
3. **로컬 txt 파일**: 지원 브라우저(Chrome/Edge)에서는 "이 기기 파일에 실시간 저장 연결" 버튼으로 로컬 `.txt` 파일에 매 기록마다 자동 저장할 수 있습니다. 미지원 브라우저는 "지금 다운로드" 버튼을 사용하세요.

## 최초 설정 (부스 기기에서 1회)

1. `admin.html`을 열고 PIN을 새로 설정합니다(이 기기의 1차 잠금).
2. "⚙️ GitHub 동기화 설정"을 펼쳐 owner/repo/branch를 확인하고, **이 저장소에만 쓰기 권한이 있는 fine-grained personal access token**(Contents: Read and write)을 발급해 붙여넣고 저장합니다.
   - 토큰은 이 브라우저의 `localStorage`에만 저장되며 저장소에 커밋되지 않습니다.
   - 토큰이 없는 기기는 GitHub에 쓸 수 없으므로, 이것이 "이 기기에서만 입력 가능"을 실질적으로 보장하는 장치입니다. `admin.html` 링크와 PIN, 토큰을 외부에 공유하지 마세요.
3. GitHub 저장소 Settings → Pages에서 배포 브랜치를 지정해 `index.html`을 공개합니다.

## 개발

```bash
npm install
npm run build     # src/*.ts → assets/*.js 컴파일
npm run watch     # 변경 감지 자동 빌드
```

정적 파일만 제공하면 되므로 아무 정적 서버로 로컬 확인이 가능합니다.

```bash
python3 -m http.server 8000
```
